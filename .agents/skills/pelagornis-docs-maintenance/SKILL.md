# Pelagornis documentation maintenance

## Purpose

Keep documentation accurate, navigable, and aligned with the implementation.

## Workflow

1. Inspect existing documentation conventions and identify affected pages.
2. Verify technical claims against the implementation or an authoritative source.
3. Update the smallest set of pages needed, avoiding duplicated guidance.
4. Check navigation, internal links, and code examples.
5. Build or validate the documentation where practical.

## Output

Summarize documentation changes, affected links or navigation, and validation results.

## Boundaries

Do not invent behavior or publish claims that have not been verified.

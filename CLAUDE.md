# Pelagornis Styleguide

This repository maintains Pelagornis engineering standards and shared Agent Skills.

## Instructions

- Inspect the existing architecture before making changes.
- Prefer established repository conventions over unnecessary abstractions.
- Keep canonical shared Skills in `.agents/skills/`.
- Use a relevant Skill when its workflow matches the task.
- Do not duplicate canonical Skill content in agent-specific directories.
- Run relevant validation before reporting completion.

## Verification

Report actual validation results and any checks that could not run.
